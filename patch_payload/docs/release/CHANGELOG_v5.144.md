# E4 D&D v5.144.0 Release Candidate Packaging

This release candidate consolidates the playable runtime completion work delivered through v5.143.

## Included

- Class and subclass runtime resources with rest recovery
- Spell slot, concentration, duration, damage and healing runtime
- Feat uses, item charges and attunement feedback
- Session play history and manual runtime bridge
- Content coverage and playability audits
- Context-aware production security gate
- Bundle splitting and performance budgets
- Persistent getting-started onboarding
- Offline PWA build and backup/recovery flows

## Release status

v5.144.0 is the packaging gate before the v6.0.0 first public playable release.
