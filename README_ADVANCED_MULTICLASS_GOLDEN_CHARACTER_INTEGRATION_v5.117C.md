# E4 D&D v5.117C — Golden Multiclass Character Integration

ZIP içeriğini proje köküne çıkarıp dosyaların üzerine yaz.

```powershell
powershell -ExecutionPolicy Bypass -File .\APPLY_ADVANCED_MULTICLASS_GOLDEN_CHARACTER_INTEGRATION_v5.117C.ps1
```

Bu paket gerçek Level-Up Assistant'a multiclass skill ve musical instrument
seçimlerini ekler. Rogue Thieves' Tools otomatik kaydedilir. Seçimler Character
Edit normalizasyonundan sonra da korunur.
