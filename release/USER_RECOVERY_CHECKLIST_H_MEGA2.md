# H-MEGA2 User Recovery Checklist

- [ ] Export or copy the current character save
- [ ] Preserve the original save unchanged
- [ ] Record app and schema versions
- [ ] Validate the backup
- [ ] Attempt hydration and migration
- [ ] Restore the backup if validation fails
- [ ] Confirm character level, HP, resources, spells and equipment
- [ ] Confirm Play Mode and combat state
- [ ] Confirm reload persistence
- [ ] Confirm offline/PWA shell
