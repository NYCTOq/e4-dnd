# Everything for D&D v6.0.0

First public playable release.

## Highlights

- Character creation and advancement from level 1 to 20.
- Class, subclass, spell, feat, item and inventory workflows.
- Play Mode with action economy, resources, conditions, concentration and rests.
- Session history and manual runtime bridge for effects requiring table judgement.
- Offline-capable PWA, backup and recovery tools.
- Accessibility, onboarding, security and bundle-performance gates.
