# E4 D&D v5.131 — Subclass Runtime Completion Mega

## Gerçek oynanış geliştirmeleri
- Play Mode subclass aksiyonlarında kalan/max kullanım görünürlüğü.
- Subclass aksiyonu harcandığında erişilebilir canlı geri bildirim.
- Kaynak yoksa veya action economy doluysa açıklayıcı geri bildirim.
- Shared subclass kaynaklarının merkezi ve güvenli tüketimi.
- Short rest sırasında yalnız short-recovery kaynaklarının yenilenmesi.
- Long rest sırasında short + long kaynaklarının yenilenmesi.
- Manual ve unlimited kaynakların otomatik rest tarafından bozulmaması.
- Multiclass karakterlerde ortak resource dizisinin tek kuralla korunması.
