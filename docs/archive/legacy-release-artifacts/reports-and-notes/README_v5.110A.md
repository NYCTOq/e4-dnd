# v5.110A Equipment & Combat Reference Oracle

UI'dan bağımsız equipment/combat referansı kurar. Inventory, weight, weapon attack/damage, fighting styles, armor/shield AC, mastery, combat readiness ve 250+ deterministik senaryo içerir.

Kurulum:

```powershell
powershell -ExecutionPolicy Bypass -File .\APPLY_EQUIPMENT_COMBAT_REFERENCE_ORACLE_v5.110A.ps1
```

Tekrar çalıştırma:

```powershell
npm.cmd run certify:equipment-combat:quick
```

Uygulama kodunu değiştirmez ve E2E içermez.
