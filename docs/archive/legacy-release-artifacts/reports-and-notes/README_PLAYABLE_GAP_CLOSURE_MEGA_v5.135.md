# E4 D&D v5.135 — Playable Gap Closure Mega

Adds a persistent Manual Runtime Bridge to Play Mode for mechanics that do not yet have dedicated automation. Effects are character-scoped, survive reloads, support finite or indefinite duration, advance by round, can be removed manually, and are recorded in the session timeline.

Run `APPLY_PLAYABLE_GAP_CLOSURE_MEGA_v5.135.ps1` from the project root after copying this folder's contents over the project.
