This package moves from isolated class checks to cross-catalog player character scenarios.

Coverage:

- D&D 2014 and D&D 2024
- all 12 core classes
- checkpoint levels 1, 3, 4, 5, 8, 11, 17 and 20
- 192 generated character creation scenarios
- race / ancestry assignment
- background assignment
- subclass selection timing
- feat / ASI slot visibility
- primary ability, save and skill configuration
- class spell-list availability
- complete 1-20 progression
- all class builder certification suites
- full character creation and level 1-20 journey suites
- full unit/integration suite
- production build

```powershell
cd D:\Projects\e4_dnd

```
